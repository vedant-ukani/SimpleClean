# Source materials

This directory contains user-provided evidence and read-only inputs for the Simple Clean project. The files are organized by how they support the product work:

- `transcripts/` — dated conversation transcripts used as requirements evidence.
- `inventory/` — the immutable inventory workbook and the Laundrorama equipment photographs.
- `operations/` — shipping instructions, the workflow whiteboard, and washer/dryer checklists.
- `archive/duplicates/` — retained duplicate source files. The workflow whiteboard copy is byte-identical to the original and is archived for provenance; it is intentionally not deleted.

The source files are preserved as received. Do not edit, normalize, overwrite, or commit the large binary inputs without an explicit reason and review. References in the repository point to these paths, and the inventory workbook remains the read-only migration input for local acceptance.
