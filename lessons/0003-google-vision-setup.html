Set up Google Vision for the 92-photo test

Create one Google Cloud project, enable billing and Cloud Vision, create a restricted API key, then store it only in the ignored local .env file.

Keep the key private

Do not paste the key into chat, commit it, or place it in .env.example. The repository ignores .env.

1. Create or select a project

  1. Open the Google Cloud project selector.
  2. Create a project named laundrorama-ocr-evaluation, or select an existing test project.
  3. Attach a billing account. Google requires billing even when usage remains within the free tier.

2. Enable Cloud Vision

  1. Open the Cloud Vision API page.
  2. Confirm the correct project is selected.
  3. Click Enable.

3. Create and restrict the key

  1. Open APIs & Services → Credentials.
  2. Choose Create credentials → API key.
  3. Name it laundrorama-ocr-local-benchmark.
  4. Under API restrictions, choose Restrict key and select Cloud Vision API.
  5. For this short local test, leave application restrictions unset unless the Mac has a stable public IP. Delete or rotate the key after the benchmark.

Google recommends restricting every API key. See Manage API keys.

4. Store it locally

Open /Users/vedant/Desktop/Simple Clean/.env and add or replace:

INTAKE_RECOGNITION_VERIFIER_API_KEY=your_restricted_google_key

Do not change the permanent provider setting. The benchmark command selects Google only for that run.

5. Tell the agent “done”

The agent will verify only that the value is present, then run all 92 images with the exact same one-megapixel preprocessing used for PaddleOCR. Expected usage is 92 billable image units; the first 1,000 Vision units each month are currently free.

What happens next

The result will compare serial, model, manufacturer, voltage and phase accuracy, plus average/p95 latency and estimated cost. No provider will be selected until both reports use the same manifest and image bytes.

Primary source: Google Cloud Vision setup documentation. Ask the agent if any Console label differs or the project shows a permission/billing error.
