Simple Clean · INT-02

More pixels are not the same as more cost

Learn to separate three decisions: whether Intake may safely accept an image, what Google Vision charges for, and how Gemini turns an image into input tokens.

The key distinction

Raising INTAKE_RECOGNITION_MAX_PIXELS from 1M to 20M is an acceptance safety limit. It lets the local Files pipeline consider larger images; it does not change Google Vision billing and it does not promise better recognition. For a raw 12MP image, the practical cost is mainly transfer time, latency, and memory pressure.

Two services, two meters

Local Files gate

Checks bytes and pixels before recognition begins.

Google Vision

Document Text Detection is billed per image, not per pixel.

Gemini

Charges by text, image-token, output, and thinking usage.

Vision's first 1,000 units each month are free; units after that are listed at $1.50 per 1,000 for Document Text Detection. The free tier depends on what else the billing account has used. Check the official Vision pricing table.

Gemini 3 image tokens

Gemini 3.6 Flash's default or unspecified image resolution is approximately 1,120 image tokens. high is also approximately 1,120; ultra_high is approximately 2,240. Resolution trades detail against latency and cost, so measure accuracy on the same labeled nameplate set before changing it.

The current Simple Clean Gemini adapter does not explicitly set media_resolution; the request therefore leaves that choice unspecified. See media resolution and token counting.

Retrieval check

Before you continue, answer from memory: if a 12MP photo is rejected at a local 1M-pixel gate, did Vision charge for it, and did Gemini receive it? Explain why in one sentence.
